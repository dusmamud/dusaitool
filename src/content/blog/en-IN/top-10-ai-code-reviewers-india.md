These ten review pull requests for bugs and security flaws. Limits vary by source.

1. CodeRabbit reviews PRs; public repos free.
2. Copilot reviews PRs; needs paid Pro.
3. Qodo reviews PRs; PR-Agent self-hosted free.
4. Greptile reviews codebases; free 50 credits.
5. Sourcery reviews Python; public repos free.
6. Codacy tracks quality; free tier editor-only.
7. Snyk Code finds flaws; free 100 tests.
8. DeepSource reviews PRs; open source free.
9. SonarQube checks quality; Community Build free.
10. Semgrep scans code; Community CLI free.
