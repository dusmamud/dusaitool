These ten tools draft code documentation, working in India without VPN.

1. Mintlify builds MDX docs; AI trial.
2. GitBook syncs docs with Git; free.
3. Fern builds docs, SDKs; 250 free credits.
4. ReadMe builds API references; free Starter.
5. Theneo generates API docs; free Starter.
6. Notion AI drafts wikis; Business plan.
7. Scribe turns clicks into guides; free.
8. Docusaurus builds free docs; no AI.
9. DocuWriter.ai generates docs from code; 7-day trial.
10. DeepWiki generates wikis; public repos free.

## FAQ

**Which tool is best for API docs?** Fern, ReadMe lead; Theneo suits small teams.

## Final verdict

Start with Fern for free AI docs and Mintlify for polished MDX sites.
